## Problem 3

Let $$G=\mathbb{Z}\times\mathbb{Z}$$ and let $$H$$ be the subgroup of $$G$$ generated by $$(1,1)$$ and $$(2,0)$$.

a) Write down explicitly the distinct cosets of $$G/H$$

b) Determine what finite Abelian group $$G/H$$ is isomorphic to, in invariant factor form

**Solution:**

a) The subgroup $$H$$ is given by

$$H = \{a(1,1) + b(2,0): a,b\in\mathbb{Z}\} = \{(a+2b,a): a,b\in\mathbb{Z}\}.$$

If $$(x,y)\in G$$, then 

$$(x,y) \equiv (x,y)-y(1,1) = (x-y,0)\mod H.$$

Furthermore, if $$x-y$$ is even, then $$x-y=2k$$ for some integer $$k$$ and therefore

$$(x-y,0) \equiv (x-y,0)-k(2,0) = (0,0)\mod H.$$

If $$x-y$$ is instead odd, then $$x-y=2k+1$$ for some integer $$k$$ and therefore

$$(x-y,0) \equiv (x-y,0)-k(2,0) = (1,0)\mod H.$$

Thus the only two cosets are

$$(0,0) + H = \{(a+2b,a): a,b\in\mathbb{Z}\},$$

$$(1,0) + H = \{(a+2b+1,a): a,b\in\mathbb{Z}\}.$$

b) The group $$G/H$$ has two elements, so we know automatically it is isomorphic to $$\mathbb Z_2$$.

## Problem 4

a) State the definition of two elements in a ring being associates

b) Define the greatest common divisor of two elements $$a,b$$ in an integral domain $$R$$.

c) Give an example of an integral domain with two elements which do not have a greatest common divisor

**Solution:**

a) Two elements $$a$$ and $$b$$ are associates if there exists a unit $$u$$ in the ring with $$a=ub$$.

b) The greatest common divisor is an element $$c\in R$$ which divides both $$a$$ and $$b$$, and with the property that if $$d$$ divides both $$a$$ and $$b$$, then $$d$$ must divide $$c$$.

## Problem 5

Let $$G$$ be a cyclic group and suppose that $$N$$ is a normal subgroup of $$G$$.
Prove that $$G/N$$ is also a cyclic group.

**Solution:**
Since $$G$$ is cyclic, there exists $$g\in G$$ with $$G = \langle g\rangle$$.

We claim that $$G/N = \langle gN\rangle$$.
Obviously, $$\langle gN\rangle \subseteq G/N$$, so to prove our claim it suffices to prove that $$G/N\subseteq \langle gN\rangle$$.
Suppose $$xN\in G/N$$.
Then $$x\in G$$, so there exists an integer $$k$$ with $$x = g^k$$.
It follows that

$$xN = g^kN = (gN)^k\in \langle gN\rangle.$$

Hence $$G/N\subseteq \langle gN\rangle$$, and we conclude that $$G/N = \langle gN\rangle.$$
This proves that $$G/N$$ is cyclic.


## Problem 6

Prove that if $$G$$ is a finite Abelian group and $$n=pq$$ is a product of two different primes which divides the order of $$G$$, then $$G$$ has an element of order $$n$$.
Hint: use the Structure Theorem in prime divisor form.

By the structure theorem, we know that there is an isomorphism

$$\varphi: G\rightarrow \mathbb Z_{p_1^{k_1}}\times\mathbb Z_{p_2^{k_2}}\times\dots\times\mathbb Z_{p_r^{k_r}}$$

for some collection of primes $$p_1,\dots, p_r$$ and positive integers $$k_1,\dots, k_r$$.
It follows that

$$\lvert G\rvert  = p_1^{k_1}p_2^{k_2}\dots p_r^{k_r}.$$

Also, since $$pq$$ divides $$\lvert G\rvert$$, we know that $$p$$ and $$q$$ both divide $$\lvert G\rvert$$.
Therefore $$r\geq 2$$ and at least one of the $$p_j$$'s must be $$p$$ and another one must be $$q$$.
After reordering, without loss of generality we may take $$p_1 = p$$ and $$p_2 = q$$, so that the map $$\varphi$$ is

$$\varphi: G\rightarrow \mathbb Z_{p^{k_1}}\times\mathbb Z_{q^{k_2}}\times\mathbb Z_{p_3^{k_3}}\times\dots\times\mathbb Z_{p_r^{k_r}}$$

The element $$(p^{k_1-1},q^{k_2-1},0,\dots, 0)$$ is nonzero and

$$m(p^{k_1-1},q^{k_2-1},0,\dots, 0) = (0,0,0,\dots, 0)$$

if and only if 

$$(mp^{k_1-1},mq^{k_2-1},0,\dots, 0) = (0,0,0,\dots, 0),$$

which is true if and only if

$$
mp^{k_1-1}\equiv 0\mod p^{k_1}
\quad\text{and}\quad
mq^{k_2-1}\equiv 0\mod q^{k_2}
$$

This in turn is true if and only if

$$
m\equiv 0\mod p
\quad\text{and}\quad
m\equiv 0\mod q
$$

Since $$p$$ and $$q$$ are relatively prime, this is true if and only if  $$m$$ is a mulitiple of $$pq$$.

The order of $$(p^{k_1-1},q^{k_2-1},0,\dots, 0)$$ is the smallest positive number $$m$$ with $$m(p^{k_1-1},q^{k_2-1},0,\dots, 0) = (0,0,0,\dots, 0)$$, so we conclude that the order is $$pq$$.

## Problem 7

a) State the First Isomorphism Theorem for Groups
b) Explain why

$$\text{SL}_2(\mathbb{R}) = \left\lbrace\left(\begin{array}{cc}a & b\\c & d\end{array}\right): ad-bc=1\right\rbrace$$

is a normal subgroup of 

$$\text{GL}_2(\mathbb{R}) = \left\lbrace\left(\begin{array}{cc}a & b\\c & d\end{array}\right): ad-bc\neq 0\right\rbrace$$

c) Prove that

$$\text{GL}_2(\mathbb{R})/\text{SL}_2(\mathbb{R})\cong\mathbb{R}^\times,$$

where here $$\mathbb{R}^\times=\mathbb{R}\backslash\{0\}$$ with binary operation given by multiplication.


**Solution:**

a) The First Isomorphism Theorem for Groups says that if $$\varphi: G\rightarrow H$$ is a group homomomorphism, then

$$G/\ker(\varphi)\cong \text{img}(\varphi).$$

b) The determinant map is a group epimorphism

$$\det: \text{GL}_2(\mathbb{R})\rightarrow\mathbb{R}^\times,$$

where here $$\mathbb{R}^\times=\mathbb{R}\backslash\{0\}$$ with binary operation given by multiplication.

The kernel of this map is the set

$$\{A\in \text{GL}_2(\mathbb{R}): \det(A)=1\} = \text{SL}_2(\mathbb R).$$

Therefore by the First Isomorphism Theorem

$$\text{GL}_2(\mathbb{R})/\text{SL}_2(\mathbb{R}) = \text{GL}_2(\mathbb{R})/\ker(\varphi)\cong \text{img}(\varphi) = \mathbb{R}^\times. $$
